# 實機測試清單

所有功能目前只在 Android 15 模擬器(Pixel 介面)上跑過。這份清單列出需要在實體手機上確認的項目,
依重要性排序;前面的區塊沒過,後面的就先不用測。

每一項的格式是「操作 → 預期結果」。不符合預期時,請記下**手機型號、Android 版本、哪一項、實際看到什麼**,
有當機或畫面異常的話附上記錄檔(見最後一節)。

## 0. 準備

- [ ] 電腦上執行 `scripts/fetch-depth-model.ps1` → 顯示模型已存在或下載完成(99 MB)。
- [ ] 手機開啟 USB 偵錯並接上電腦,執行 `./gradlew.bat :app:installDebug` → 安裝成功。
- [ ] 手機相簿裡準備:一張風景照、一張人像照、一段直式手機錄影(有聲音)、一段橫式影片、
      2–3 張透明背景 PNG(分層測試用,沒有可略過第 5 節)。

## 1. 基本流程(必須先過)

- [ ] 開啟 App → 匯入 → 圖片 → 選一張照片 → 桌布庫出現縮圖,標示「主畫面+鎖定」。
- [ ] 按「設為系統桌布」→ 系統預覽頁顯示該圖 → 選「主畫面和鎖定畫面」→ 主畫面顯示該圖。
- [ ] 鎖定螢幕再點亮 → 鎖定畫面也顯示該圖。**這是各廠牌差異最大的一項**:
      若鎖定畫面顯示的是別的桌布,請記下廠牌與系統版本。
- [ ] 桌面有多頁時左右滑動 → 比螢幕寬的圖片會跟著橫移。
- [ ] 重開機 → 解鎖後桌布仍是 App 的桌布。
- [ ] 重開機後**尚未解鎖前**的鎖定畫面 → 顯示 App 的桌布(不是黑畫面或系統預設)。

## 2. 影片桌布

- [ ] 匯入 → 影片 → 選**直式手機錄影** → 出現進度對話框(有聲音的影片會轉檔)→ 完成後桌布庫出現縮圖。
- [ ] 主畫面 → 影片在播放,**方向正確**(沒有橫躺或上下顛倒),沒有聲音。
- [ ] 觀察循環接點 → 回到開頭時沒有明顯停頓或黑畫面。
- [ ] 匯入一段**橫式影片** → 置中裁切填滿螢幕,滑動桌面頁時橫移。
- [ ] 匯入一段解析度高於螢幕的影片(例如 4K)→ 匯入成功;在桌布包匯出的 zip 裡檢查 `video.mp4` 明顯小於原檔。
- [ ] 匯入 HDR 影片(若手機能拍)→ 顏色正常,沒有泛白。
- [ ] 開啟任一 App 蓋住桌布幾分鐘再回到主畫面 → 影片繼續播放,沒有卡在黑畫面。

## 3. 照片轉空間桌布

- [ ] 匯入 → 照片轉空間桌布 → 選風景照 → 效果選「無」→ 建立。記下**分析花了幾秒**。
- [ ] 主畫面左右傾斜手機 → 近處與遠處朝相反方向移動,有立體感。請評估:
  - [ ] **方向**是否自然(像透過窗戶看景物)。若感覺相反請告知。
  - [ ] **靈敏度**:輕微傾斜就到底,還是要傾斜很多才有感覺。
  - [ ] **回正**:手機保持傾斜幾秒後畫面慢慢回到中間 — 速度是否合適。
- [ ] 上下傾斜 → 也有對應的上下視差。
- [ ] 手機平放在桌上不動 → 畫面完全靜止,沒有抖動或飄移。
- [ ] 視差強度拉到最大再建立一次 → 檢查物體邊緣的拉伸是否可接受。
- [ ] 用**人像照**再做一次 → 人物與背景有分離感,頭髮邊緣沒有嚴重破圖。
- [ ] 選一張很大的照片(例如 5000 萬畫素)→ 不當機。
- [ ] 分別用「光塵」「飄雪」「下雨」建立 → 效果正常,動畫流暢不卡頓。

## 4. Shader

- [ ] 匯入 → Shader / 插件包 → 內建範例 → 三個範例(沙丘視差、流動極光、水波漣漪)都能加入並顯示。
- [ ] 水波漣漪:點擊與滑動主畫面空白處 → 出現擴散的波紋(另外每兩秒會自動落一滴,這是設計)。
- [ ] 沙丘視差:滑動桌面頁 → 沙丘各層以不同速度移動。
- [ ] 匯入 → 新建 Shader → 開啟編輯器。**螢幕鍵盤彈出時**,程式碼區與「儲存」按鈕仍可操作,沒有被鍵盤蓋住。
- [ ] 在編輯器裡故意打錯字 → 儲存 → 底部出現紅色錯誤面板與行號,桌布不變。
- [ ] 改回正確 → 儲存 → 提示「已儲存並套用」,桌布與縮圖更新。
- [ ] 點該桌布 → 調整參數 → 拖動「流動速度」→ 放開後桌布的流動速度改變。
- [ ] 從電腦傳一個 `.frag` 檔到手機 → 匯入 → Shader 檔案 → 能選到並匯入。
- [ ] 貼一個較重的 Shadertoy shader → 觀察是否自動降低解析度維持流暢(畫面會變得稍微模糊)。

## 5. 分層空間桌布

- [ ] 匯入 → 分層空間桌布 → 依「背景 → 中景 → 前景」順序選圖 → 調整各層深度 → 建立。
- [ ] 傾斜手機 → 背景不動,越前面的圖層移動越多,前景邊緣沒有露出切邊。

## 6. 主畫面與鎖定畫面分別指定

- [ ] 點桌布 A →「只套用到主畫面」;點桌布 B →「只套用到鎖定畫面」→ 卡片分別標示「主畫面」「鎖定」。
- [ ] 鎖定螢幕再點亮 → 鎖定畫面顯示 B。
- [ ] 用**你平常的方式解鎖**(指紋、臉部、PIN)→ 主畫面顯示 A。若停在 B 沒切換,請記下解鎖方式。
- [ ] 把 B 換成影片 → 鎖定畫面上影片有在播放。

## 7. 省電與耗電

- [ ] 開啟系統省電模式 → 動畫凍結、影片暫停、傾斜無反應;關閉後恢復。
- [ ] 套用影片桌布,正常使用半天 → 到「設定 → 電池」查看 Planetarium 的耗電比例,記下數字。
- [ ] 同樣測一次「飄雪」空間照片與「水波漣漪」。這兩種會持續以 30fps 繪製,預期最耗電。
- [ ] 套用效果為「無」的空間照片,手機靜置 → 耗電應接近靜態桌布。
- [ ] 手機明顯發燙或桌面滑動變卡 → 記下是哪一種桌布。

## 8. 桌布包管理

- [ ] 點桌布 → 重新命名 → 桌布庫顯示新名稱。
- [ ] 點桌布 → 匯出為 .zip → 選位置儲存。
- [ ] 刪除該桌布(確認對話框 → 刪除)→ 從桌布庫消失。
- [ ] 匯入 → Shader / 插件包 → 插件包(.zip)→ 選剛才匯出的檔 → 桌布回來且內容相同。
- [ ] 刪除**使用中**的桌布 → 桌布變成深色空畫面,不當機;再套用另一個即可恢復。

## 9. 其他

- [ ] 設定 → 桌布與樣式 → 主題色有跟著桌布顏色變化(Android 12 以上)。
- [ ] 旋轉手機到橫向(若桌面支援)→ 桌布重新填滿,沒有變形。
- [ ] 摺疊機:開合螢幕 → 桌布重新填滿。
- [ ] 系統更新 App(重新執行安裝指令)→ 桌布不需要重新套用。

## AI 生成桌布(需要網路)

從「新增桌布 → AI 生成桌布」進入。這是 App 裡唯一會連網的畫面。

- [ ] 畫面是單欄:上方預覽,下方「AI 助手/圖層/調整」三個分頁,沒有被狀態列或導覽列蓋住。
- [ ] 點輸入框 → 鍵盤彈出後輸入框和「送出」仍看得到。
- [ ] 設定 → 選 ChatGPT → 登入:跳到瀏覽器的 OpenAI 登入頁;登入後頁面顯示「登入完成」,按「回到 Planetarium」回到同一個畫面,設定裡顯示已登入的帳號。
- [ ] 設定 → 測試連線 → 顯示成功。
- [ ] 輸入一段描述並送出 → 圖層一層一層出現在預覽;整個過程(約數分鐘)螢幕不會自動關閉。
- [ ] 生成途中按「停止」→ 立刻停下,已畫好的圖層還在。
- [ ] 「＋ 參考圖」→ 可以從相簿選圖,縮圖出現在輸入框上方。
- [ ] 「圖層」分頁:點眼睛可以隱藏圖層;點一個圖層後到「調整」分頁可以改遠近。
- [ ] 「套用為桌布」→ 提示已加入桌布庫;按返回,桌布庫第一張就是它,而且已經是目前的桌布。
- [ ] 桌布庫點一張分層桌布 →「用 AI 修改(另存為新桌布)」→ 那張桌布的圖層出現在畫面裡。
- [ ] 離開再進來 → 上次做到一半的圖層還在。
- [ ] 飛航模式下進入 → 畫面仍可開啟、可編輯圖層;送出訊息時顯示連線錯誤而不是當掉。

## 已知行為(不是錯誤)

- AI 生成時要讓 App 留在前景;切到別的 App 太久,系統可能中斷連線,需要重新送出。
- 「用 AI 修改」開啟的是點陣圖層,AI 只能整層重畫,不能微調原稿;內建桌布的動畫貼片不會帶進去。

- 在「設定 → 應用程式」對 Planetarium 按**強制停止**,系統會把桌布重設回預設,需要回 App 重新按「設為系統桌布」。
- 桌面只有一頁時,比螢幕寬的圖片會顯示最左側而不是置中。
- 越前面的圖層會被放大越多(避免傾斜時露邊)。
- 部分廠牌(尤其 Samsung)的鎖定畫面可能不顯示第三方動態桌布,這是系統限制。

## 回報問題時附上記錄檔

重現問題後,手機接著電腦執行:

```
adb logcat -d -v time > planetarium-log.txt
```

把 `planetarium-log.txt` 交給我即可。裡面是手機的系統記錄,可能包含其他 App 的名稱與通知標題,
若有顧慮可以只擷取含 `planetarium`、`Renderer`、`Scene`、`VideoLayer`、`ShaderLayer`、`AndroidRuntime` 的行:

```
adb logcat -d -v time | findstr /i "planetarium Renderer Scene VideoLayer ShaderLayer AndroidRuntime" > planetarium-log.txt
```
